## What matters most when choosing classes

-   What you need for progress, not just what looks interesting right now.
-   How hard the overall mix feels together.
-   Whether the class times match how you actually function.
-   How much walking, waiting, and friction the schedule creates.

## A smarter way to decide

| Question | Why ask it |
| --- | --- |
| Do I need this class now? | Priority should start with progress, not novelty. |
| What does this class add to the overall load? | One more hard class can change the whole quarter. |
| Does this fit my best hours? | Time matters more than students like to admit. |
| What do grade patterns and section differences suggest? | Data is not everything, but it helps. |
