# UCSB Lagoon — Web

> The interactive, gamified central hub for UCSB student life.
> Companion to the Lagoon mobile app. Shares the same Supabase backend.

A Next.js 15 + Supabase app that turns the things UCSB students already do —
checking in, rating dining halls, attending events — into XP, levels, badges,
and weekly leaderboards.

## Stack

| Layer        | Choice                                     |
|--------------|--------------------------------------------|
| Framework    | **Next.js 15** (App Router, RSC, Turbopack)|
| Styling      | **Tailwind v4** (CSS-first `@theme`)       |
| Backend      | **Supabase** (Postgres, Auth, Realtime)    |
| Charts       | **Recharts** + custom SVG                  |
| Animation    | **Framer Motion**                          |
| Icons        | **Lucide**                                 |
| Auth         | Supabase magic link, shared with mobile    |
| Hosting      | Vercel (separate project from marketing)   |

## Getting started

```bash
cd web
cp .env.example .env.local       # fill in your Supabase URL + anon key
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000).

### First-run database setup

1. Link the Supabase CLI to your existing project:
   ```bash
   npx supabase link --project-ref <YOUR_REF>
   ```
2. Apply the gamification migration:
   ```bash
   npx supabase db push
   ```
   (Or paste `supabase/migrations/0001_gamification.sql` into the SQL editor.)
3. Generate typed bindings:
   ```bash
   npm run db:types
   ```

## How it stays in sync with the mobile app

Both clients **share the same Supabase project** — same `auth.users`, same
gamification tables. All XP-granting actions go through one Postgres function:

```sql
select public.grant_xp('checkin', 'spots', 'davidson-library');
```

This is the single source of truth. Web and mobile never duplicate
point-granting logic.
