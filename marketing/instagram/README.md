# Lagoon Instagram assets

Public, ready-to-post marketing images for @ucsblagoon. **Every screen uses demo data**
("Alex", a made-up eight-course week, made-up classmates) — no real student appears.

- Source of truth: the private app repo, `AppStoreMedia/ads/generate_ads.py` and
  `AppStoreMedia/generate_screenshots.py`. Regenerate there, then copy here.
- Operating prompt for the social bot: [`docs/grok-instagram-prompt.md`](../../docs/grok-instagram-prompt.md)
- Bio / ad link: `https://apps.apple.com/app/apple-store/id6760681142?pt=123978416&ct=ig_bio&mt=8`
  (new ad campaigns: same link with a new `ct=` tag)

## Rules for using these

- Don't change the claims on the images or add new ones (no user counts, ratings, or "official UCSB").
- Crop or reframe only within the navy / cream / gold / pastel palette; no gradients, shadows or stock people.
- Lagoon is not affiliated with UC Santa Barbara — never pair these with UCSB logos or the seal.
