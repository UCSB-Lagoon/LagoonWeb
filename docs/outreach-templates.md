## 5. TikTok / Reel hook list (first 30 days)

Top-performing UCSB-specific hooks. Aim for 7-15s videos. Hook in the first 1.5s.

1. **"POV: it's 11:48am and you don't know which dining hall to go to"** — open Lagoon, compare 4 menus on screen, walk to winner
2. **"Things UCSB doesn't tell you: the grade distribution for {{popular class}} is…"** — show the screen, react
3. **"I dropped this class after checking one screen"** — grade data + GOLD sync demo
4. **"Storke Plaza this week"** — events feed scroll, set to trending audio
5. **"The 6 apps I deleted after getting Lagoon"** — phone home screen, drag-to-delete
6. **"Why everyone in IV is putting this app on their home screen"** — split-screen testimonial style
7. **"DLG vs. Ortega vs. Carrillo vs. Portola — ranked by today's menu"** — live demo + opinion
8. **"How to actually use GOLD without losing your mind"** — GOLD sync workflow
9. **"Things only Gauchos understand"** — relatable montage with subtle app cameos
10. **"App built by 3 UCSB students just hit X downloads"** — milestone post + behind-the-scenes

## 6. Meta Ads — creative briefs

### Ad 1 — Hero install (cold)
- **Audience:** 18-24, located within 10mi of UCSB / Goleta / Isla Vista
- **Objective:** App Installs
- **Hook:** "Tired of using 6 apps to be a UCSB student?"
- **Body:** "Schedule, dining menus, grades, events, news — one app. Free. Built by Gauchos."
- **Creative:** 7s screen recording of GOLD sync → dining menu → grade data
- **CTA:** Install Now

### Ad 2 — Dining utility (cold)
- **Hook:** "Don't bike to Ortega without checking this first."
- **Creative:** 5s screen recording of live menu compare
- **Body:** "Live UCSB dining menus, updated all day. Free."
- **CTA:** Install Now

### Ad 3 — Grade data (cold, intent-heavy during W1/W10)
- **Hook:** "Before you sign up for that class…"
- **Creative:** Screen recording of grade distribution chart for a notorious GE
- **Body:** "Real UCSB grade distributions for every course. Free."
- **CTA:** Install Now

### Ad 4 — Retargeting (warm — site visitors who didn't install)
- **Audience:** Custom audience from Meta pixel
- **Hook:** "Still thinking about it?"
- **Body:** "Lagoon is free, takes 10 seconds to set up, replaces 6 campus apps."
- **CTA:** Install Now
